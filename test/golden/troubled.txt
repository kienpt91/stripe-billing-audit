  Why it matters:

    trusted to come from where it claims. Stripe requires HTTPS for live-mode endpoints.

    verifying the Stripe-Signature header regardless of the transport.

[MEDIUM] webhook-api-version-drift: API version differs from the account's on 1 endpoint
  Evidence:
    - Account default version: 2025-09-30.clover.
    - we_1HttpE… (http://hooks.example.com/stripe/…) is pinned to 2020-08-27.
  Why it matters:
    The payload of an event follows the API version of its endpoint. If the endpoint and the account
    differ, the shape your handler receives differs from what the rest of your code reads from the
    API, and an account upgrade changes only one of them.
  Fix:
    Choose one version on purpose: set the endpoint's version to the one your handler was written
    against, or upgrade handler and account together. Test the handler against payloads of the
    target version before switching.
